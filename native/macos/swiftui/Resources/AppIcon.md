# FrankenCodeBrowser icon

Created with OpenAI's built-in image generation tool. `AppIcon.png` is the original image with transparency; `AppIcon.icns` contains the standard macOS 16, 32, 128, 256, and 512-point representations at 1× and 2×. The app bundle script installs the ICNS resource and declares it in Info.plist.

To regenerate the ICNS, resize the original PNG using `sips -z` into an `AppIcon.iconset` directory, with filenames `icon_16x16.png`, `icon_16x16@2x.png`, and the equivalent pair for each point size above. Package with `iconutil -c icns AppIcon.iconset -o AppIcon.icns`. Preserve the source alpha channel.
